## Acerca de NexCam

**NexCam** es la marca personal de Cristian Alexander Camacho Pira, Ingeniero de Sistemas y Desarrollador Full Stack con más de 4 años de experiencia construyendo aplicaciones empresariales, transaccionales y de prevención de fraude para el sector financiero colombiano.

Perfil DevSecOps que diseña, construye, despliega y protege software de extremo a extremo:
- Desarrollo backend con **Java / Spring Boot** y microservicios
- Desarrollo frontend con **Angular** y **React**
- Contenedores con **Docker**, nube **AWS** y **Cloudflare**
- Pipelines **CI/CD** (Jenkins, GitLab, Azure DevOps)
- Seguridad de aplicaciones (**AppSec**, **PCI-DSS**)
- Soluciones con **Inteligencia Artificial** (OpenAI, Claude API, Langchain)
